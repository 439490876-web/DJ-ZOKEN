# Skill: zh-docs-and-skills

目的
- 强制 Codex 在本项目及后续相关任务中，默认输出“中文说明文档 + 中文 skill 内容”。
- 让文档、README、方案说明、skills、注释说明等保持统一语言与风格。

适用范围
- 说明文档：README.md、设计文档、API 文档、接口契约说明、迁移方案、变更说明、changelog
- skills：任何新建/更新的 SKILL.md、stack.md、skills 目录内容
- 对话输出：计划、步骤、风险点、使用方式、命令说明等

硬性规则（必须遵守）
1) 默认中文：所有解释性内容必须使用简体中文。
2) 允许保留英文但需克制：
   - 命令/代码/路径保持原样（bash/python/json/ts 不翻译）
   - 专有名词可保留英文：FastAPI、uvicorn、Vite、Git LFS、Discogs Effnet、Serato、Rekordbox 等
3) 英文输出的例外：
   - 当用户明确要求英文
   - 当内容是日志/报错/代码/CLI 输出（保持原文）
4) 文档风格：
   - 标题清晰，分点列表优先
   - 每个结论尽量给“可执行步骤”
   - 避免空泛口号，强调可落地
5) 如果输出包含模板或字段说明：
   - 字段名保持英文（schema/key）
   - 字段解释使用中文
6) 如果需要生成“skill”：
   - SKILL.md 的正文必须中文
   - “How to use / 使用方法”章节必须中文
   - 允许在示例命令中保留英文

交付格式（建议）
- 先给：目标与范围
- 再给：步骤清单（可复制执行）
- 再给：风险点与回滚办法（若涉及文件操作）
