# Liquid Glass UI 设计文档

**目标**
- 在不改变功能与信息结构的前提下，升级为 macOS 液态玻璃视觉风格。
- 保持操作流与字段语义不变，仅调整视觉、布局比例、动效与一致性。
- 新增应用内可见主题切换（Warm Glass / Neutral Smoke）。

**硬性约束**
- 不增删功能，不改交互流程，不改接口与字段含义。
- 色彩避开明显蓝紫/赛博霓虹，保持暖中性与可读性。
- 强化玻璃层：blur + saturate + brightness + 细边框 + 多层柔和阴影。
- 统一圆角体系：大卡片 18-22px，小控件 10-14px。

**总体架构**
- 使用全局 CSS Tokens（theme.css）驱动颜色、圆角、阴影、模糊、间距与字体层级。
- 主题切换通过根节点 `data-theme` 控制，Warm 为默认，Neutral 覆盖变量。
- 玻璃组件抽象为 GlassPanel / GlassCard / GlassButton，所有三栏核心面板统一使用。

**布局与组件策略**
- 三栏比例：中间主舞台 44~48%，左右收窄；顶部 header 高度统一。
- 右侧诊断区拆成“诊断/统计/图表/AI”清晰分层；卡片 top padding 对齐。
- 列表项改为克制的玻璃卡片 + Pill 标签体系，选中态采用描边高亮。
- 图表区域使用轻玻璃底，网格线更淡，空状态更中性系统提示感。

**交互动效**
- hover 提亮 + 边框更清晰；press 0.98~0.99 轻缩放。
- 过渡 160~220ms，曲线 cubic-bezier(0.2, 0.8, 0.2, 1)。
- 支持 prefers-reduced-motion 降动效。

**回滚思路**
- 视觉变更集中在 theme.css、Glass 组件与 App.tsx 主要样式。
- 一键回滚：移除 theme.css 引用与新增组件，恢复旧样式变量。
