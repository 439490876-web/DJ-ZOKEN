# SPIN FLOW 日落渐变 UI 设计优化方案

## 目标与范围
- 目标：减轻视觉沉重感，营造更强烈的日落渐变氛围，并重构能量曲线色彩体系。
- 范围：仅视觉样式与图表绘制方式调整，不改变功能与交互逻辑。

## 视觉方向
- 背景：日落天空渐变（暖橙/柔粉 → 暮光紫 → 深靛蓝），叠加轻微噪点纹理与环境光晕。
- 玻璃面板：提高透明度，减少“厚实感”，让背景层透出更多色彩。
- 强调色：全局强调色改为暖金色/落日橙，用于按钮、选中态、关键提示。
- 光影：边缘与按钮加入柔和暖色光晕，模拟日落余晖照亮感。

## 组件与层级策略
- 左右侧面板：透明度更高、饱和度更低，作为“后退层”。
- 中央工作区：保持相对清晰与明亮，承接主要操作与信息。
- 按钮：采用软糖/磨砂糖果质感（内发光 + 温暖渐变）。
- 输入框：统一胶囊形玻璃输入，聚焦时暖色光晕增强。

## 能量曲线（Energy Flow）
- 语义：曲线高度 = 能量；曲线颜色 = 热度（resonance/heat）。
- 色谱分级（严格遵循）：
  - 1-3 低：Deep Ocean Blue → Cyan（#0B1D3A → #2EC4D6）
  - 4-5 中低：Teal → Lime Green（#1F9E9A → #7BC96F）
  - 6-7 中高：Warm Yellow → Orange（#F4C45E → #F28C3B）
  - 8-9 高：Deep Orange → Magenta（#E26A2C → #C04B9B）
  - 10 极高：Vibrant Red → Blazing Fuchsia（#E93B2F → #E23BB8）
- 表现：
  - 曲线采用“逐段着色路径”绘制，每段使用热度映射的线性渐变。
  - 曲线下方区域采用同色半透明渐变填充，增强体量感。
  - 峰值（能量局部最大值）以对应热度色发光点强调。

## 实现要点（前端）
- 全局主题：通过 `index.html` 中 CSS 变量统一控制背景渐变、玻璃透明度、暖色光晕。
- 图表绘制：在 Recharts 中使用 `Customized` 组件进行分段曲线绘制。
- 色彩映射：热度值按分段区间线性插值计算颜色。
- 降噪与回退：面板阴影改为暖色扩散光，降低厚重阴影感。

## 可访问性与交互
- 保留可见的键盘焦点状态。
- 文字对比度不低于可读阈值（背景渐变上仍可清晰阅读）。

## 风险与回滚
- 风险：分段曲线绘制可能导致渲染开销略增。
- 回滚：将自定义分段曲线恢复为 Recharts 默认 `Area` 绘制即可。
