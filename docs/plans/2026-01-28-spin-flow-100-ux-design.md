# SPIN FLOW 高级感 UI/UX 100 套方案设计稿（HTML 预览）

## 目标与范围
- 目标：生成 100 套可对比的高保真 UI 方案，用于“SPIN FLOW”DJ 生产力工具主仪表盘预览选择
- 输出：单一 HTML 文件（无需构建工具），可在浏览器直接浏览、筛选与放大预览
- 约束：不改功能，仅改外观；允许使用通用占位内容（虚拟文案/假数据/占位图）

## 已确认需求
- 展示方式：B（布局筛选 + 主题筛选的过滤式浏览）
- 布局策略：10 个构图骨架（混合均衡），每个骨架 10 个主题变体（共 100 套）
- 页面范围：单一页面类型（主仪表盘/生产台）
- 字体：允许外部字体 CDN

## 信息架构与交互结构
- 顶栏：品牌 + 10 个布局筛选 Pills + 10 个主题色牌 + 缩放滑块
- 主体：响应式预览卡片网格（移动端 1 列、平板 2 列、桌面 3-4 列）
- 卡片：内嵌缩略屏幕框架，显示导航条、能量曲线、关键控制区与队列统计
- 交互：
  - hover 提升亮度/阴影，不改变尺寸
  - 点击卡片触发展示放大预览浮层（仅视觉，不涉及真实功能）
- 可访问性：键盘可聚焦、可见 focus 样式、`prefers-reduced-motion` 降级

## 视觉体系（高级感优先）
- 方向：暮光日落玻璃拟态（高透明度 + 漫射阴影 + 柔和环境光）
- 背景：橙粉 → 暮光紫 → 深靛蓝纵向渐变，叠加轻微噪点
- 面板：高透明度玻璃，柔和边框与分层阴影
- 强调色：暖金/落日橙；避免科技蓝
- 按钮：柔和渐变 + 轻内发光
- 曲线：平滑线 + 轻微发光；关键点发光强调

## 10 个构图骨架（L1-L10）
- L1：中央舞台 + 双侧工具抽屉（左右两栏 + 中央大画布）
- L2：三栏密集信息（左导航/中舞台/右参数塔）
- L3：顶部巨型能量曲线 + 下方双区卡片
- L4：左侧资源树 + 右侧多列卡片矩阵
- L5：上下分屏（上控制、下时间线队列）
- L6：右侧大舞台 + 左侧细长控件列（反常规）
- L7：中轴对称 + 中央主控 + 两侧镜像数据
- L8：卡片瀑布流 + 浮动关键指标胶囊
- L9：分屏网格（2×2 主面板 + 角落迷你统计）
- L10：实验布局（环形仪表/半环能量曲线 + 环绕控件）

- T1：暖夕金（暖金 + 轻烟灰）
- T2：薄暮玫瑰（玫瑰粉 + 暮光紫）
- T3：陶土珊瑚（珊瑚橙 + 米灰）

- T6：暮云烟灰（烟灰蓝 + 低饱和粉）
- T7：夜幕墨紫（深紫 + 暖灰）
- T8：霓光暖橙（暖橙 + 玫粉）
- T9：雾粉杏金（杏金 + 柔雾）
- T10：深海暮紫（深靛 + 灰紫）

## 颜色与曲线映射
- 能量曲线高度代表能量；颜色代表热度
- 热度色谱（用于曲线渐变与关键点）：
  - 1-3：Deep Ocean Blue → Cyan
  - 4-5：Teal → Lime Green
  - 6-7：Warm Yellow → Orange
  - 8-9：Deep Orange → Magenta
  - 10：Vibrant Red → Blazing Fuchsia

## 实现策略（单一 HTML）
- 结构：`header` + `main`（卡片网格）+ `aside`（放大预览浮层）
- 数据：`layouts[]` + `themes[]` 配置生成 100 卡片
- 渲染：JS 组合布局与主题，卡片编号为 `Lx-Ty`
- 曲线：SVG path + 线性渐变描边 + 轻发光；峰值点发光强调
- 响应式：375/768/1024/1440 断点，避免横向滚动

## 风险与回滚
- 风险：单一 HTML 文件较大，加载初次可能略慢
- 缓解：使用轻量 SVG、无外部图片或仅使用低体积占位图
- 回滚：删除生成的 HTML 与本设计文档即可恢复

## 验收标准
- 100 套方案可筛选浏览，编号清晰
- 视觉统一高端、轻盈、通透；无“科技蓝”
- 曲线颜色与热度映射一致，关键点发光可见
- 移动端无横向滚动，交互清晰
